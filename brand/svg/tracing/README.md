# Volty SVG Tracing Workspace

이 폴더는 Volty를 SVG로 옮기기 위한 작업 공간이다.

중요:

- 여기 있는 tracing SVG는 최종 캐릭터 SVG가 아니다.
- 기준 시안을 임베드해서 비율, 얼굴, 후드, 의상을 확인하는 작업 보드다.
- 실제 캐릭터 SVG는 이 보드 위에서 트레이싱하고 `templates/character-asset-review.md` 검수를 통과한 뒤에만 `brand/svg/` 기준 자산으로 등록한다.

## Files

- `volty-canonical-trace-board.svg`: 1안 외형 reference와 2안 의상 reference를 함께 놓은 작업 보드

외형은 `volty-canonical-bbotjjak-panel.png`를 따른다.
