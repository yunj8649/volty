# Volty Poses

`brand/svg/drafts/volty-base-front.svg`를 기준으로 만든 기본 포즈 15종 개별 SVG다.

## Files

- `01-standing.svg`: 일어서기
- `02-sitting.svg`: 앉아있기
- `03-reading-book.svg`: 책 읽기
- `04-writing.svg`: 필기하기
- `05-laptop.svg`: 노트북 하기
- `06-thinking.svg`: 생각하기
- `07-passed-test.svg`: 시험 합격
- `08-intense-study.svg`: 열공하기
- `09-coffee.svg`: 커피 마시기
- `10-fighting.svg`: 화이팅
- `11-charging.svg`: 충전하기
- `12-confused.svg`: 헷갈려요
- `13-idea.svg`: 아이디어
- `14-running.svg`: 달리기
- `15-lightning-power.svg`: 번개 파워

## Rule

- 베이스 캐릭터 실루엣을 유지하고 소품, 손, 동작선만 추가한다.
- 새 포즈를 만들 때 후드 모양과 몸 비율을 새로 그리지 않는다.
- 모든 파일은 독립 실행 가능한 SVG다.
- 승인 전 1차 제작본이므로 실제 인스타툰 컷에 넣어 작은 크기 검수를 한다.
